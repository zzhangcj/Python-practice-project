# 1、登录页面 Login.vue
创建src/views目录下，Login.vue
```vue
<template>
  <div class="login-container">
    <div class="login-box">
      <h1 style="font-size: 28px">实验室预约系统</h1>
      <div style="margin-top: 5px; margin-bottom: 30px">基于Agent智能预约系统</div>

      <el-form :model="form" label-width="auto" style="max-width: 600px">
        <el-form-item>
          <el-input
            size="large"
            v-model="form.username"
            placeholder="请输入账号"
            :prefix-icon="User"
          />
        </el-form-item>
        <el-form-item>
          <el-input
            type="password"
            size="large"
            v-model="form.password"
            placeholder="请输入密码"
            :prefix-icon="Lock"
            show-password
          />
        </el-form-item>
        <div>
          <el-button
            size="large"
            type="primary"
            style="width: 100%"
            @click="login"
            :loading="loadingValue"
            >登 录</el-button
          >
          <div style="text-align: right; margin-top: 20px">
            还没有账号？请 <a style="color: var(--el-color-primary)" href="/register">注册</a>
          </div>
        </div>
      </el-form>
    </div>
  </div>
</template>

<script setup>
import { reactive, ref } from 'vue'
import { User, Lock } from '@element-plus/icons-vue'
import { ElMessage } from 'element-plus'
import router from '@/router'

const form = reactive({
  username: '',
  password: ''
})

const loadingValue = ref(false)

const login = () => {
  loadingValue.value = true
  setTimeout(() => {
    loadingValue.value = false
    ElMessage.success('登录成功')
    router.push('/manager/home')
  }, 2000)
}
</script>

<style scoped>
.login-container {
  height: 100vh;
  display: flex;
  justify-content: center;
  align-items: center;
}
.login-box {
  width: 380px;
  border-radius: 8px;
  box-shadow: 0 8px 12px rgba(0, 0, 0, 0.1);
  padding: 30px;
  text-align: center;
  background-color: white;
}
</style>
```

**注意**：想要看到页面，在http://localhost:5173/login
就是在这个地址后面写上login

# 3、路由配置index.js

```javascript
import { createRouter, createWebHistory } from 'vue-router'

const router = createRouter({
  history: createWebHistory(import.meta.env.BASE_URL),
  routes: [
    { path: '/', redirect: '/manager/home' },
    {
      path: '/manager',
      name: 'Layout',
      component: () => import('@/layouts/Layout.vue'),
      children: [
        { path: 'home', name: 'Home', component: () => import('@/views/Home.vue') },
        { path: 'lab', name: 'Lab', component: () => import('@/views/Lab.vue') }
      ]
    },
    { path: '/login', name: 'Login', component: () => import('@/views/Login.vue') },
    { path: '/register', name: 'Register', component: () => import('@/views/Register.vue') }
  ]
})

export default router
```

```vue
<div>
  <el-dropdown>
    <div style="display: flex; align-items: center; cursor: pointer">
      <img src="@/assets/imgs/logo.png" alt="" style="width: 30px; border-radius: 50%" />
      <div style="margin-left: 3px">管理员</div>
    </div>
    <template #dropdown>
      <el-dropdown-menu>
        <el-dropdown-item @click="logout">退出登录</el-dropdown-item>
      </el-dropdown-menu>
    </template>
  </el-dropdown>

```

将同一文件的 `<script setup>` 替换为以下代码，保留原有菜单图标导入，并添加退出方法：

```vue
<script setup>
import { Menu as IconMenu, House, Setting, User } from '@element-plus/icons-vue'

  router.push('/login')

```

**大致效果**
模拟登录，退出时只跳转到登录页。
运行项目后，将鼠标移到右上角的头像或“管理员”上，点击“退出登录”，应进入 `/login` 页面。


# 5、零散的知识点总结

## 一、Login.vue
- 1、**Vue3 单文件组件（SFC）标准结构**
  页面分为 `<template>` 结构、`<script setup>` 逻辑、`<style scoped>` 样式三部分；`scoped` 表示样式只作用于当前组件，不会污染全局。
- 2、**响应式数据定义**
  - `reactive`：定义对象型响应式数据，适合存放表单集合（如 form 包含账号、密码）
  - `ref`：定义基本类型响应式数据，适合存放单一状态（如 loadingValue 控制按钮加载）
- 3、**表单双向绑定 v-model**
  输入框内容与数据变量实时同步，无需手动操作 DOM 获取值，是 Vue 最核心的特性之一。
- 4、**Element Plus 表单类组件**
  - `el-form`：表单容器，`:model` 绑定整个表单数据对象
  - `el-input`：输入框，支持 size 尺寸、prefix-icon 前缀图标、`type="password"` 密码模式、`show-password` 密码显隐切换
  - `el-button`：按钮，`type="primary"` 主色调样式，`:loading` 绑定加载状态
- 5、**事件绑定 @click**
  点击按钮触发对应方法，是最基础的用户交互写法。
- 6、**路由跳转 router.push()**
  登录成功后编程式跳转到后台首页，替代传统 a 标签跳转，不刷新页面。
- 7、**全局消息提示 ElMessage**
  操作后给出轻量反馈（成功、失败、警告），是后台系统通用交互方式。
- 8、**加载状态交互优化**
  点击登录后开启按钮 loading，防止重复提交，用 `setTimeout` 模拟接口请求延迟。
- 9、**全屏居中布局**
  `height: 100vh` + flex 水平垂直居中，是登录页、注册页的经典布局方案。
- 10、**主题色变量调用**
  `var(--el-color-primary)` 直接使用 Element Plus 内置主色变量，保证全局色彩统一，换主题时自动跟随。

## 二、Register.vue
> 和 Login 页面结构高度相似，重点掌握：
- 1、**多字段表单扩展**
  在 `reactive` 中新增 `confirmPassword` 字段，快速实现确认密码等额外表单项。
- 2、**页面间锚点跳转**
  原生 `<a href="/login">` 实现登录、注册页互相跳转，适合无需传参的简单跳转。
- 3、**同类页面复用思路**
  登录、注册页采用完全一致的「全屏居中 + 卡片 + 表单」结构，可复用布局逻辑与样式写法。

## 三、Layout 退出登录
- **下拉菜单组件 el-dropdown**
  鼠标悬浮/点击弹出操作菜单，非常适合右上角头像、用户中心这类场景。
- **具名插槽 `template #dropdown`**
  用来放置下拉菜单的自定义内容，是 Vue 插槽的常用写法。
