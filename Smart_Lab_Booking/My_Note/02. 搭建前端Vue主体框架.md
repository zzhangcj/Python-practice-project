## 1、改造 App.vue 作为项目入口

```javascript
<template>
  <router-view />
</template>
```
**这里为什么要改成如此精简？**

>App.vue 是**整个 Vue 项目的根入口组件**；
>加了路由之后，它不再用来直接写页面内容，只负责**承载路由渲染出来的页面**。

**详细解释**

1. **原来的版本（带 h1、按钮、链接）** 
- 这是 Vue 初始化后的默认演示页面，所有内容都直接写在 App.vue 里。 
- 👉 缺点：只有这一页，没有页面跳转功能，写死在这里，没法区分首页、预约页、管理页等不同页面。
-
1. **`<router-view />` 是什么** 
>它是 vue-router 提供的**路由占位标签**： 根据浏览器地址栏的路由路径，自动把**对应页面组件**渲染到这个位置。

- `/login` → 登录页面渲染到 router-view
- `/booking` → 实验室预约页面渲染到 router-view

2. **分工逻辑（重点，项目标准写法）**
    - App.vue：根壳子（可以放导航栏、侧边栏、footer + `<router-view/>`），**不写具体页面业务内容**
    - views/ 文件夹下面：放一个个独立页面（首页、预约页等）
    - router/index.js：配置路径和页面组件的映射关系

**用到的 Element Plus 组件清单**
1. **el-container**：布局容器，用于搭建页面骨架，内置 flex 布局，嵌套使用实现上下+左右组合布局
2. **el-header**：头部容器，放置系统标题、logo、用户信息
3. **el-aside**：侧边栏容器，承载左侧菜单，固定宽度
4. **el-main**：主体内容容器，用来放置 `<router-view />`，展示路由页面
5. **el-menu**：菜单组件，开启 `router` 属性，点击菜单项自动跳转路由
6. **el-menu-item**：菜单项，对应每一个导航跳转入口
7. **el-icon**：图标容器，用来渲染导入的图标

**Layout.vue 作用总结**
Layout.vue 是后台管理系统的公共布局壳组件，作为嵌套路由的父组件：
1. 承载整套固定页面骨架：顶部标题栏、用户信息、左侧侧边菜单栏；
2. 内部包含 `<router-view />`，用来渲染 Home、Lab 这类子业务页面；
3. 实现共用布局复用：多个页面共用一套头部和侧边栏，切换子页面时，骨架不会重新加载，只切换中间主体内容。



##  4、router/index.js路由文件

```javascript
import { createRouter, createWebHistory } from 'vue-router'

const router = createRouter({
  history: createWebHistory(import.meta.env.BASE_URL),
  routes: [
    { path: '/', redirect: '/manager/home' },
    {
      path: '/manager',
      name: 'Layout',
      component: () => import('@/layouts/Layout.vue'),
      children: [
        { path: 'home', name: 'Home', component: () => import('@/views/Home.vue') },
        { path: 'lab', name: 'Lab', component: () => import('@/views/Lab.vue') }
      ]
    }
  ]
})

export default router
```

知识点：**嵌套路由**
嵌套路由就是路由存在父子层级关系，用来实现**页面局部复用布局骨架**。
1. 父路由对应布局壳（Layout.vue），里面必须有 `<router-view />`；
2. 子路由挂载在父路由的 `children` 数组中，子页面渲染在父组件内部的路由出口； 
3. 切换子页面时，父布局（头部、侧边栏）保持不变，只更换中间主体内容；
4. 适合后台管理系统这类多页面共用一套侧边+顶部布局的场景。

## 7、总结

### 组件职责说明
- **App.vue**：整个 Vue 项目的根入口组件，只放 `<router-view />`，所有路由页面都在这里渲染
- **Layout.vue**：后台布局壳组件（父路由页面），包含顶部栏、侧边菜单、内部的 `<router-view/>`，专门给嵌套子页面提供统一骨架
- **router/index.js**：路由配置文件，统一管理全部路由规则：路径、组件、重定向、嵌套父子关系，控制页面跳转
- **Home.vue、Lab.vue**：Layout 下的子页面组件，渲染在 Layout 内部的 router-view 里

### 访问流程
访问 `/manager/home`
1. 根 App.vue 的 `<router-view />` 先渲染 Layout.vue
2. Layout.vue 展示顶部栏、侧边菜单，同时提供自身内部的 `<router-view />`
3. 将 Home.vue 渲染到 Layout 内部的 `<router-view />`
