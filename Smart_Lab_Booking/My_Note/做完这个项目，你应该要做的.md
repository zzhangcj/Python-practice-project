# 1、接口流程你要清楚

登录接口这套流程：定义请求体模型 → 拿到 db 会话 → 查询数据库用户 → 判断密码 → 返回统一格式的 json。这套逻辑是后端最通用的模板，以后写新增、查询、修改接口都是同一个套路
# 2、怎么写接口你要会
