**vue 工程设置格式化  .prettierrc.json**
```json
{
  "$schema": "https://json.schemastore.org/prettierrc",
  "semi": false,
  "singleQuote": true,
  "tabWidth": 2,
  "trailingComma": "none",
  "printWidth": 100
}
```

**搜索 打开 settings.json（用户打开）**
设置文件保存格式化：

```json
{
  "editor.formatOnSave": true,
  "editor.formatOnPaste": true,
  "[vue]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode"
  },
  "[javascript]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode"
  },
  "[json]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode"
  }
}
```

逐条解释(了解)：
1. `"editor.formatOnSave": true` **保存文件的时候自动格式化代码**（Ctrl+S 自动对齐、调整引号、换行）。
2. `"editor.formatOnPaste": true` 粘贴代码进来的时候，自动格式化粘贴的内容。 
3. `[vue] / [javascript] / [json]` 这三块 给 vue、js、json 文件，指定默认格式化工具为 Prettier 
> 一句话总结： 开启粘贴、保存自动格式化，Vue/JS/JSON 统一用 Prettier，再加两个编辑器小便利设置

## 4、安装**Element-Plus**
在终端里操作：
```bash
cd .\frontend\
npm install element-plus -S
```
Element Plus 是一套 **基于 Vue3 的 UI 组件库**
简单说：**帮你直接拿现成好看的页面组件，不用自己从零写 CSS 样式**。

**快速开始**

```css
import ElementPlus from 'element-plus'
import 'element-plus/dist/index.css'
app.use(ElementPlus)
```

**国际化 中文配置**

```javascript
import zhCn from 'element-plus/es/locale/lang/zh-cn'

app.use(ElementPlus, {
  locale: zhCn,
})
```

**图标 icon**

```bash
npm install @element-plus/icons-vue
```

**全局注册图标**

```javascript
import * as ElementPlusIconsVue from '@element-plus/icons-vue'

for (const [key, component] of Object.entries(ElementPlusIconsVue)) { app.component(key, component)}
```

## 5、配置全局 css 文件 assets/css /global.css
创建src/assets/css/global.css
（两个文件夹，一个css文件）
```css
* {
  box-sizing: border-box;
}
/* 盒状模型 */

html,
body,
#app {
  width: 100%;
  min-height: 100%;
  margin: 0;
  padding: 0;
}

body {
  font-family: "Microsoft YaHei", sans-serif;
  font-size: 14px;
  color: #303133;
  background-color: #f5f7fa;
}

/* 清除标题默认边距 */
h1,
h2,
h3,
h4,
h5,
h6,
p {
  margin: 0;
}

/* 清除列表默认样式 */
ul,
ol {
  margin: 0;
  padding: 0;
  list-style: none;
}

/* 链接 */
a {
  color: inherit;
  text-decoration: none;
}

/* 图片 */
img {
  max-width: 100%;
}
```
如果链接这里不起作用：
```css
/* 链接 */
a,
a:link,
a:visited {
  color: inherit;
  text-decoration: none;
}
```
## 6、main.js

```javascript
import { createApp } from 'vue'
import App from './App.vue'
import router from './router'
import ElementPlus from 'element-plus'
import 'element-plus/dist/index.css'
import zhCn from 'element-plus/es/locale/lang/zh-cn'
import * as ElementPlusIconsVue from '@element-plus/icons-vue'
import '@/assets/css/global.css'

const app = createApp(App)

app.use(router)
app.use(ElementPlus, {
  locale: zhCn
})
for (const [key, component] of Object.entries(ElementPlusIconsVue)) {
  app.component(key, component)
}

app.mount('#app')
```
