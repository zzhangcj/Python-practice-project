## 📂 文件夹说明
### `.idea/`
PyCharm自动生成的本地配置文件夹，只保存在自己电脑。
> 💡 规范建议：不要上传到GitHub，可以在.gitignore里配置忽略该文件夹。

### `leetcode_1/`
算法刷题代码，包含数组、链表、二叉树、回溯、深度/广度优先搜索等常见题型，每道题目独立保存为py文件。

### `pomodoro/`
简易命令行番茄计时器，小型控制台程序练习。

### `Python_learning_notes/`
Python基础、进阶知识点笔记，附带配套演示代码。

### `python_practice1/`
文件操作实战项目，使用Python标准库实现文件批量管理、压缩解压、操作日志等功能。

### `python_review/`
Python面试高频知识点练习脚本：基础类型、函数、面向对象、装饰器、异常处理、生成器等。
